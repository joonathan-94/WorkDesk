Estados

Cambia el nombre visible y la descripción (que aparece como ayuda al pasar el cursor sobre el estado). El código interno no cambia. El color y el orden son parte del diseño del flujo y no se editan. Los cambios de nombre se ven en toda la aplicación; el historial de cada ticket conserva el nombre que tenía el estado cuando ocurrió cada cambio.

Transiciones

Son las que WorkDesk define como válidas: no se crean otras. Deshabilitar una hace que esa acción deje de ofrecerse desde ese estado, de inmediato y para todos los tickets; los tickets no cambian de estado.

Protegida marca las transiciones que no se pueden deshabilitar: las esenciales para el flujo (como la confirmación del solicitante) y las que dejarían algún estado sin salida o sin entrada. Habilitar siempre se puede.
