{# --- Cómo se usan -------------------------------------------------------- #}

Cómo se crean, comprueban y restauran

En el servidor, con el entorno virtual activado y desde la carpeta del proyecto:

Crear un respaldo (WorkDesk puede seguir en uso):

python -m flask --app src.workdesk backup-create

Comprobar uno sin restaurarlo (no necesita la base de datos):

python -m flask --app src.workdesk backup-verify NOMBRE
Restaurar reemplaza la base de datos y los adjuntos por los del respaldo: se pierde lo que se hizo después. Detén antes WorkDesk y el planificador. El comando lo comprueba todo, pide escribir el nombre de la base, guarda antes un respaldo de lo actual y cierra todas las sesiones.
python -m flask --app src.workdesk backup-restore NOMBRE
